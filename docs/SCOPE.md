# V1 scope — proposed

Deliver accurate, consistent and access-controlled operational reporting with visible data quality while preserving existing source workflows. Target demonstration within 90 days; feasibility and funding not yet validated.

Start with a single departmental proof of concept (source selection pending), then expand only after validation of mapping, security and refresh behavior. All four departments are the intended V1 coverage; if feasibility requires reduced coverage, sponsor approval and clear dashboard labeling are required.

In scope: FR-01 through FR-08 and NFR-01 through NFR-05 in [requirements](REQUIREMENTS.md). Deferred: AI summaries, prediction, export enhancements, mobile-specific design, source-system replacement, automated recommendations.

UAT triage: defect or unmet agreed requirement returns to development; security failures block release; enhancement requests enter backlog; scope changes require impact assessment and sponsor approval. No silent expansion.
